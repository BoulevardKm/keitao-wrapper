# Keitaro wrapper

Небольшой сервис поверх [Keitaro Admin API](https://admin-api.docs.keitaro.io/): создаёт кампанию с двумя потоками и правит офферы уже существующей кампании. В трекер изменения попадают только по кнопке публикации.

## Что делает

Создание кампании принимает название, гео (`MX, AU`) и id оффера.

- Кампания крутит потоки по позиции. Затраты — CPC, 0 USD, значение берётся из параметра `cost`.
- Домен, группа и источник ищутся в API по именам из `.env` (`in.posdk.xyz`, `FORTESTS`, `FORTESTS`).
- Первый поток принимает перечисленные страны и редиректит их на `https://google.com`.
- Второй поток без фильтра забирает всех остальных и ведёт на выбранный оффер со долей 100%.

Редактор открывает кампанию по id или alias.

- **Fetch streams** заново читает потоки. Поток без офферов показывается строкой: фильтры и URL редиректа не разбираются. Оффер, который исчез из Keitaro, остаётся в архиве серым, с долей 0. Добавление, которое ещё не публиковали, при загрузке пропадает.
- **Добавить** ищет оффер в Keitaro и пересчитывает доли. Поток становится жёлтым: в трекере пока старые данные.
- **Push to Keitaro** записывает активные офферы и их доли. **Cancel** возвращает поток к последнему загруженному или опубликованному состоянию.
- **Remove** не удаляет строку. Оффер сереет, доля становится 0, после публикации его нет в Keitaro, а **Bring back** возвращает его в поток.
- **Запинить** фиксирует текущую долю. Следующие добавления и удаления пересчитывают только незапиненные офферы. Сумма активных долей всегда 100. Это целые проценты; остаток от деления получают офферы с меньшим id. Три оффера — это 34%, 33% и 33%, а не три раза по 33.

## Запуск

Нужен Python 3.12+. Команды из корня проекта.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m app.migrate
python -m uvicorn app.main:app --reload
```

macOS и Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.migrate
python -m uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000

В `.env` нужен ключ из админки Keitaro: Профиль → API ключи. Без него страницы открываются, а запросы в трекер отвечают понятной ошибкой. Файл `.env` в git не коммитится.

`python -m app.migrate` применяет Alembic к базе из `DATABASE_URL`. По умолчанию это файл `data/app.db` (SQLite). Модели не привязаны к диалекту: в `DATABASE_URL` можно поставить другой адрес SQLAlchemy, если для него установлен драйвер.

## Проверки

```bash
python -m pytest
```

Тесты не ходят в Keitaro: создание кампании, пересчёт долей, архив, пин, публикация и отмена проверяются на подставном клиенте API.
